Internal Tool

Clip Sync

A private internal dashboard built to securely upload video media files and sync draft captions with your TikTok account.

How It Works

Clip Sync monitors a secure cloud folder. When a new video is added, it:

  • Transcribes the audio using Groq's Whisper API
  • Generates an optimized title and description using OpenRouter (Llama 3 70B)
  • Uploads the video as a draft to your TikTok account

Data Privacy

We respect your privacy. Your videos are processed only for the purpose of creating draft posts. No content is stored permanently or shared with third parties beyond the essential services (Groq for transcription, OpenRouter for caption generation).
